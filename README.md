# 업무 비서

업무 비서는 맥북에서 동작하는 로컬 업무 검색 앱입니다. 내 과거 Claude Code 세션과 Slack, Confluence, Jira, GitHub를 한꺼번에 검색해 출처와 함께 답해 줍니다. 서버나 클라우드 없이 내 맥북 한 대에서만 돌아가고, 세션 데이터는 밖으로 나가지 않습니다.

## 필요한 프로그램

먼저 아래 프로그램이 설치되어 있어야 합니다. 앱의 처음 설정 화면에서 설치 여부를 확인해 줍니다.

- macOS 12.3 (Monterey) 이상
- OrbStack 또는 Docker Desktop
- Ollama
- Claude Code
- Xcode 명령줄 도구 (`xcode-select --install`)

## 설치

1. 최신 릴리스에서 `.dmg` 파일을 내려받습니다.
2. `.dmg`를 열고 `업무 비서.app`을 Applications 폴더로 끌어다 놓습니다.
3. 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면 아래 두 방법 중 하나로 엽니다.
   - 시스템 설정 → 개인정보 보호 및 보안 → 하단의 "그래도 열기"를 누릅니다.
   - 또는 터미널에서 다음 명령을 실행한 뒤 다시 엽니다.
     ```bash
     xattr -dr com.apple.quarantine "/Applications/업무 비서.app"
     ```

## 처음 설정

처음 실행하면 처음 설정 화면이 나옵니다. 화면의 안내를 따라 아래 순서로 진행합니다.

1. 필수 프로그램이 설치되어 있는지 확인합니다.
2. 내 GitHub 조직과 Atlassian 사이트 정보를 입력합니다.
3. 검색 스킬을 설치합니다.

설정이 끝나면 비서를 켜고 질문할 수 있습니다.

## 보안 원칙

- 세션 데이터는 로컬에서만 처리합니다. 임베딩은 내 맥의 Ollama가 만들고, MCP 포트는 `127.0.0.1`에만 열립니다.
- 저장·임베딩 전에 토큰, 키, 비밀번호 같은 민감정보를 마스킹합니다.
- Slack, Confluence, Jira, GitHub의 내용은 질문할 때 실시간으로 조회만 하고 저장하지 않습니다.
- 모든 외부 연결은 읽기 전용입니다. 쓰기 도구는 쓰지 않거나 차단합니다.
- 토큰은 macOS 키체인에만 보관하고, 코드나 설정 파일에는 남기지 않습니다.

## 리소스

- 디스크: 이미지와 모델을 포함해 약 1.6GB
- 메모리: 비서가 켜져 있고 유휴일 때 약 290MB (Ollama 모델은 5분간 쓰지 않으면 메모리에서 내려갑니다)
